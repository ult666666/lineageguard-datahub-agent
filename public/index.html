Two runtimes. No blurred claims.

Public browser-session preview

Executes the shared DAG against same-origin synthetic tools. Checkpoints stay in this browser. There is no durable cloud queue, model inference, tenant connection or authenticated approval.

Local durable runtime

Run npm run studio:local with Node 24 to add a loopback API, durable SQLite checkpoints and writer leases. The optional MCP client keeps its explicitly tested 2025-11-25 profile.

Checksums detect corruption, not malicious same-origin edits. A local review acknowledgement is not permission to change a catalog. No execution tool exists in the registry.
